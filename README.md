
# 🔐 Digital Signature Verification System

## 📌 About
A Python-based web application that demonstrates digital signature generation and verification using RSA cryptography and SHA-256.

## 🚀 Features
- Generate digital signatures
- Verify signatures using a public key
- Check document authenticity and integrity
- Simple web interface using Flask
- Display signature verification results

## 🛠️ Technologies
- Python
- Flask
- RSA Cryptography
- SHA-256
- HTML and CSS

## ⚙️ How It Works
1. Select the original document.
2. Generate a signature using the private key.
3. Submit the document and signature for verification.
4. Verify the signature with the corresponding public key.
5. View the verification result.

## 💻 Setup
Install the required libraries:

```bash
python -m pip install Flask cryptography
```

Run the application:

```bash
python app.py
```

Open `http://127.0.0.1:5000/` in your browser if configured for this address.
